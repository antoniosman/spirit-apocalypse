# 1.3.0 validation

- `node tests/view.cjs`: encountered-first alphabetical relationships, independent player knowledge, selected/common base display, base history preservation, abandoning bases and missions.
- `node tests/intro.cjs`: individual credits for all 26 actors within 36 seconds, ordered primary players, first credit at source 1:05, six distinct episode opening images, no repeated establishing shots, asset existence and immutable historical replay.
- `CAMPAIGN_CASES_ONLY=1 node tests/campaign.cjs`: focused campaign continuity acceptance cases.
- `node tests/engine.cjs`: 300 legacy playthroughs, 1,800 episodes and 23,400 decisions.
- Browser checks: prominent decision banner and styled confirmation; canceling confirmation leaves state unchanged; encountered rows sort first in both directions; switching from Billy to Tony preserves separate knowledge; one selected common base is rendered while both historical records remain saved.
- Browser viewports: major decision at 1440×1000 and 360×800, with no horizontal overflow. Reduced-motion disables the arrival effect. Individual NPC credits show the same solo framing as player credits with name opacity 1.
- GitHub Actions runs all four suites, including complete independent campaigns, before Pages publication.

Large casts deliberately get shorter NPC shots rather than a longer intro, according to the user's selected preference. Viewport emulation is not a physical iOS/Android device test.
