ΠΩΣ ΠΑΙΖΕΙΣ
1. Αποσυμπίεσε ΟΛΟ το ZIP σε δικό του φάκελο. Μην ανοίξεις μεμονωμένα
   το index.html από το εσωτερικό του ZIP.
2. Για απλό παιχνίδι, άνοιξε το index.html με Chrome, Edge ή Firefox.
3. Πάτησε «Ξεκίνα τη σειρά» και διάλεξε 1, 2 ή 3 local παίκτες.
4. Δες το original cinematic intro ή πάτησε SKIP.
5. Διάλεγε αποφάσεις. Σε 2–3 local players ο καθένας ψηφίζει διαδοχικά.
6. Στο τέλος κάθε επεισοδίου δες τις αποφάσεις, την εμπιστοσύνη και τις
   απώλειες. Πάτησε «Επεισόδιο 2» κ.ο.κ. για τη συνέχεια.

SAVE / LOAD
- AUTO SAVE: γίνεται αυτόματα σε κάθε επιλογή και αλλαγή σκηνής.
- MANUAL SAVE: «SAVE / LOAD» πάνω δεξιά και μετά «SAVE» σε slot 1–3.
- LOAD: «LOAD» δίπλα στο αποθηκευμένο slot.
- EXPORT: κατέβασε το παιχνίδι ως αρχείο .json για αντίγραφο ασφαλείας.
- IMPORT: φόρτωσε το .json σε άλλη συσκευή ή browser.
- ΠΡΟΣΟΧΗ: τα manual slots και τα αυτόματα saves αποθηκεύονται ΤΟΠΙΚΑ
  σε κάθε browser. Αν καθαρίσεις τα δεδομένα του browser, θα χαθούν.
  Κράτα Export για βεβαιότητα.

ΠΩΣ ΝΑ ΕΓΚΑΤΑΣΤΗΣΕΙΣ ΩΣ APP (PWA)
Το κουμπί «⬇ INSTALL» βρίσκεται πάνω δεξιά.
ΑΠΟΤΕΛΕΙ ΠΕΡΙΟΡΙΣΜΟ ΤΩΝ BROWSERS ότι η εγκατάσταση PWA δεν λειτουργεί
όταν ανοίγεις το παιχνίδι από απλό file:// (index.html με διπλό κλικ).
Για install / offline χρήση απαιτείται HTTPS ή localhost.

ΕΝΑ ΠΑΡΑΔΕΙΓΜΑ ΤΟΠΙΚΟΥ SERVER ΣΤΟ PC:
  python -m http.server 8080
Μέσα στον αποσυμπιεσμένο φάκελο. Έπειτα άνοιξε:
  http://localhost:8080

Σε Chrome/Edge: πάτησε «⬇ INSTALL» και ακολούθησε την προτροπή,
ή χρησιμοποίησε το μενού του browser «Εγκατάσταση εφαρμογής».
Σε iPhone/Safari: Κοινή χρήση → Προσθήκη στην οθόνη αφετηρίας.

ΚΙΝΗΤΑ
Προσαρμόζεται για στενές οθόνες και touch. Για καλύτερη εμπειρία
χρησιμοποίησε σύγχρονο browser. Τα cast cards και οι αποφάσεις
αναδιπλώνονται σε μικρότερες στήλες και οι διάλογοι μεγαλώνουν.

ΗΧΟΣ
Αν η μουσική δεν ξεκινά αυτόματα, πάτησε μία φορά το intro ή το ♫ ON.
Οι browsers συχνά απαιτούν πρώτη ενέργεια χρήστη για αναπαραγωγή.
ΟΛΗ η μουσική γράφτηκε από την αρχή για αυτό το παιχνίδι.
Δεν περιλαμβάνονται μουσικά θέματα, βίντεο ή σκηνές του The Walking Dead.
